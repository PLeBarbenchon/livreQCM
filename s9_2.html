Chapitre 9 — Sommes et produits finis

Produits finis $\Pi$ et factorielle

$\displaystyle\prod_{k=1}^{n} 3 = 3n$
$\displaystyle\prod_{k=1}^{n} 3 = n^3$
$\displaystyle\prod_{k=1}^{n} n = n!$
$\displaystyle\prod_{k=1}^{n} n = n^n$
$\displaystyle\prod_{k=0}^{n} k = n!$
$\displaystyle\prod_{k=0}^{n} k = 2^n$
$\displaystyle\prod_{k=0}^{n} k = (n+1)!$
$\displaystyle\prod_{k=0}^{n} k = \dfrac{n(n+1)}{2}$

Le produit $\displaystyle\prod_{k=1}^{n} 3$ comporte $n$ facteurs égaux à $3$ : il vaut $3^n$ (ni $3n$, ni $n^3$). De même $\displaystyle\prod_{k=1}^{n} n = \boxed{n^n}$ ($n$ facteurs égaux à $n$, à ne pas confondre avec $n! = \prod_{k=1}^n k$). Enfin $\displaystyle\prod_{k=0}^{n} k = 0$ puisque le facteur $k=0$ est nul : aucune des quatre propositions correspondantes n'est vraie.

$\displaystyle a_{n} + \prod_{k=0}^{n} a_k$
$\displaystyle a_{n+1} + \prod_{k=0}^{n} a_k$
$\displaystyle a_{n} \times \prod_{k=0}^{n} a_k$
$\displaystyle a_{n+1} \times \prod_{k=0}^{n} a_k$
$\displaystyle n \prod_{k=0}^{n} a_k$
$\displaystyle (n+1) \prod_{k=0}^{n} a_k$

On isole le dernier facteur : $\displaystyle\prod_{k=0}^{n+1} a_k = \boxed{a_{n+1}\times\prod_{k=0}^{n} a_k}$. C'est l'analogue multiplicatif de la relation de Chasles (on multiplie, on n'ajoute pas).

$\displaystyle\lambda\prod_{k=0}^{n} a_k$
$\displaystyle n\lambda\prod_{k=0}^{n} a_k$
$\displaystyle\lambda^n\prod_{k=0}^{n} a_k$
$\displaystyle\lambda^{n+1}\prod_{k=0}^{n} a_k$

Le produit comporte $n+1$ facteurs, chacun contenant un $\lambda$ : $\displaystyle\prod_{k=0}^{n} (\lambda a_k) = \boxed{\lambda^{n+1}\prod_{k=0}^{n} a_k}$.

$\displaystyle\prod_{k=0}^{n} \left( a_k + b_k\right) = \prod_{k=0}^{n} a_k + \prod_{k=0}^{n} b_k$
$\displaystyle\prod_{k=0}^{n} \left( a_k b_k \right) = \prod_{k=0}^{n} a_k \times \prod_{k=0}^{n} b_k$
$\displaystyle\prod_{k=0}^{n} \left( a_k + 1 \right) = 1 + \prod_{k=0}^{n} a_k$
$\displaystyle\prod_{k=0}^{n} \left( 2 a_k \right) = 2^n \prod_{k=0}^{n} a_k$

Le produit est compatible avec la multiplication : $\boxed{\displaystyle\prod_{k=0}^{n} (a_kb_k) = \prod_{k=0}^{n} a_k\times\prod_{k=0}^{n} b_k}$, mais pas avec l'addition : pour $n=1$ et $a_0=a_1=b_0=b_1=1$, on a $\displaystyle\prod_{k=0}^{1}(a_k+b_k) = 4 \neq 2 = \prod a_k+\prod b_k$ et $\displaystyle\prod_{k=0}^{1}(a_k+1) = 4 \neq 2 = 1+\prod a_k$. Pour la dernière, il y a $n+1$ facteurs $2$ : $\displaystyle\prod_{k=0}^{n} (2a_k) = 2^{n+1}\prod_{k=0}^{n} a_k$.

$\displaystyle\prod_{k=1}^{n} \ln(a_k)$
$\displaystyle\sum_{k=1}^{n} \ln(a_k)$
$\displaystyle n\ln(a_n)$
$\displaystyle\ln\left(\sum_{k=1}^{n} a_k\right)$

Le logarithme transforme les produits en sommes : $\displaystyle\ln\left(\prod_{k=1}^{n} a_k\right) = \boxed{\sum_{k=1}^{n} \ln(a_k)}$ (les $a_k$ sont strictement positifs, donc tout est bien défini).

$\displaystyle\prod_{k=1}^{n} k^2 = \left( n^2 \right)!$
$\displaystyle\prod_{k=1}^{n} k^2 = \left( 2n \right)!$
$\displaystyle\prod_{k=0}^{n} 2^k = 2^{n!}$
$\displaystyle\prod_{k=0}^{n} 2^k = 2^{\frac{n(n+1)}{2}}$
$\displaystyle\prod_{k=1}^{n} (-k) = - n!$
$\displaystyle\prod_{k=1}^{n} (-k) = (-1)^{n}\, n!$

On ajoute les exposants : $\displaystyle\prod_{k=0}^{n} 2^k = 2^{\sum_{k=0}^n k} = \boxed{2^{\frac{n(n+1)}{2}}}$. On sort le signe de chacun des $n$ facteurs : $\displaystyle\prod_{k=1}^{n} (-k) = (-1)^n\prod_{k=1}^{n} k = \boxed{(-1)^n\,n!}$. Enfin $\displaystyle\prod_{k=1}^{n} k^2 = \left(\prod_{k=1}^{n} k\right)^2 = (n!)^2$, qui ne figure pas parmi les réponses.

$(2n)!$
$2^n$
$2\, n!$
$2^n \, n!$
$(n!)^2$

On sort un facteur $2$ de chacun des $n$ termes : $\displaystyle\prod_{k=1}^{n} (2k) = 2^n\prod_{k=1}^{n} k = \boxed{2^n\,n!}$.

$\dfrac{(2n)!}{n!}$
$(2n-1)!$
$\dfrac{(2n)!}{2^n\, n!}$
$2^n\, n! - 1$
$(-1)^n 2^n n!$

Le produit des impairs $1\times3\times\dots\times(2n-1)$ s'obtient en divisant $(2n)!$ par le produit des pairs $2\times4\times\dots\times2n = 2^n\,n!$ : $\displaystyle\prod_{k=1}^{n} (2k-1) = \boxed{\dfrac{(2n)!}{2^n\,n!}}$.

$n!$
$(n+1)!$
$(n+1)! - n!$
$(n+1)^n - n!$

Quand $k$ va de $0$ à $n$, le facteur $n+1-k$ prend les valeurs $n+1, n, \dots, 1$ : $\displaystyle\prod_{k=0}^{n} (n+1-k) = \boxed{(n+1)!}$ (changement d'indice $j=n+1-k$).

$1$
$\dfrac{a_{n}}{a_0}$
$\dfrac{a_n}{a_1}$
$\dfrac{a_{n+1}}{a_0}$
$\dfrac{a_{n+1}}{a_1}$

Produit télescopique : $\dfrac{a_1}{a_0}\times\dfrac{a_2}{a_1}\times\dots\times\dfrac{a_{n+1}}{a_n} = \boxed{\dfrac{a_{n+1}}{a_0}}$.

$\dfrac{1}{n}$
$\dfrac{1}{n+1}$
$\dfrac{n-1}{n}$
$\dfrac{1}{2n}$
$\dfrac{n!-1}{n!}$

$1-\dfrac1k = \dfrac{k-1}{k}$, donc par télescopage $\displaystyle\prod_{k=2}^{n} \dfrac{k-1}{k} = \dfrac12\times\dfrac23\times\dots\times\dfrac{n-1}{n} = \boxed{\dfrac1n}$.

$\dfrac{1}{n^2}$
$\dfrac{n+1}{n}$
$\dfrac{n+1}{2n}$
$\dfrac{n-1}{2n}$

$1-\dfrac{1}{k^2} = \dfrac{k-1}{k}\times\dfrac{k+1}{k}$. Les deux produits télescopent : $\displaystyle\prod_{k=2}^{n} \dfrac{k-1}{k} = \dfrac1n$ et $\displaystyle\prod_{k=2}^{n} \dfrac{k+1}{k} = \dfrac{n+1}{2}$, d'où $\boxed{\dfrac{n+1}{2n}}$.

$(n+1)^n$
$\dfrac{(n+1)^n}{n!}$
$\dfrac{n^n}{n!}$
$\dfrac{(n+1)!}{n^n}$

$\left(1+\dfrac1k\right)^k = \dfrac{(k+1)^k}{k^k} = \dfrac{(k+1)^{k+1}}{k^k}\times\dfrac{1}{k+1}$. Le premier facteur télescope en $\dfrac{(n+1)^{n+1}}{1^1}$ et le second donne $\dfrac{1}{(n+1)!}$, d'où $\displaystyle\prod_{k=1}^{n} \left(1+\dfrac1k\right)^k = \dfrac{(n+1)^{n+1}}{(n+1)!} = \boxed{\dfrac{(n+1)^n}{n!}}$. (Vérification pour $n=2$ : $2\times\frac94 = \frac92 = \frac{3^2}{2!}$.)

$\dfrac{\sin x}{\sin\left(\frac{x}{2^n}\right)}$
$\dfrac{\sin x}{2^n \sin\left(\frac{x}{2^n}\right)}$
$\dfrac{\sin x}{2^n \sin\left(\frac{x}{2^{n+1}}\right)}$
$\dfrac{\sin (2x)}{2^{n+1} \sin\left(\frac{x}{2^n}\right)}$

On utilise $\sin(2a) = 2\sin a\cos a$, soit $\cos\dfrac{x}{2^k} = \dfrac{\sin\frac{x}{2^{k-1}}}{2\sin\frac{x}{2^k}}$ (les sinus sont non nuls car $0<\frac{x}{2^k}<\pi$). Le produit télescope : $\displaystyle\prod_{k=1}^{n} \cos\dfrac{x}{2^k} = \dfrac{1}{2^n}\times\dfrac{\sin x}{\sin\frac{x}{2^n}} = \boxed{\dfrac{\sin x}{2^n\sin\left(\frac{x}{2^n}\right)}}$.

$n-1$
$n(n-1)$
$n^2$
$n(n+1)$

$n! = n(n-1)\times(n-2)!$, donc $\dfrac{n!}{(n-2)!} = \boxed{n(n-1)}$.

$2^{n-1} \leqslant n!$
$n! \leqslant 2^n$
$n! \leqslant n^n$
$(n!)^2 \leqslant n^n$

On a $n! = 1\times2\times\dots\times n$ : chacun des $n-1$ facteurs $2,\dots,n$ est $\geqslant 2$, d'où $\boxed{2^{n-1}\leqslant n!}$ ; chacun des $n$ facteurs est $\leqslant n$, d'où $\boxed{n!\leqslant n^n}$. En revanche $n!\leqslant 2^n$ est faux dès $n=4$ ($24>16$), et $(n!)^2\leqslant n^n$ est faux dès $n=3$ ($36>27$).

$\dfrac{1}{(n+1)!}$
$\dfrac{n}{(n+1)!}$
$\dfrac{-1}{n!}$
$\dfrac{n+1}{n!}$

On met au même dénominateur $(n+1)! = (n+1)\,n!$ : $\dfrac{1}{n!}-\dfrac{1}{(n+1)!} = \dfrac{(n+1)-1}{(n+1)!} = \boxed{\dfrac{n}{(n+1)!}}$.

$n!-1$
$n\times n!$
$(n+1)!$
$(n+1)!-1$

$k\times k! = (k+1)!-k!$, donc par télescopage $\displaystyle\sum_{k=1}^{n} k\times k! = (n+1)!-1! = \boxed{(n+1)!-1}$.

$(n+1)! - 1$
$n^2 \, n!$
$n \, (n+1)!$
$(n+1)! + n!$

On fait apparaître un télescopage : $k\,(k+1)! - (k-1)\,k! = \big(k(k+1)-(k-1)\big)\,k! = (k^2+1)\,k!$. Donc $\displaystyle\sum_{k=1}^{n} (k^2+1)\,k! = n\,(n+1)! - 0\times1! = \boxed{n\,(n+1)!}$. (Vérification pour $n=2$ : $2+10 = 12 = 2\times3!$.)
